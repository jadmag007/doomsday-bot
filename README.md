# ☢ Doomsday Tyranny Bot

Автоматизация игры **Doomsday Tyranny** (Telegram Mini App) на Android/Termux для
аккаунта Premium: автоматический ребут производства за 10 минут до конца
игрового цикла (фарм не прерывается), скан ресурсов с push-уведомлениями
по выбранным ресурсам, веб-панель с таймерами и настройками. Всё работает
напрямую через API игры (Firebase Cloud Functions) от вашего имени — Telegram-клиент не нужен.

> Подробная пошаговая инструкция установки — **[INSTALL.md](INSTALL.md)**.

## Что умеет

- **Авто-ребут по игровому циклу**: за 10 минут до конца цикла (настраивается) —
  фарм ресурсов не прерывается; время ребута видно на панели и в `doomsday status`
- **Скан ресурсов** каждый час: заполненность складов, состояния шахт
  («простаивает / требуется ребут / пауза / дефицит / склад переполнен»),
  все названия — на русском
- **Push-уведомления по выбранным ресурсам**: на вкладке «Ресурсы» отмечаете,
  что отслеживать (например, Сплав и Уран) — уведомления приходят только по ним;
  ничего не выбрано — по всем. Порог «близок к максимуму» настраивается
- **Веб-панель** на телефоне: таймеры (цикл производства, авто-ребут, скан),
  ресурсы, настройки, журнал событий, ручные действия
- **Мониторинг чата бота**: ловит уведомления игры, которые вы пропустили
- **Ежедневная сводка** в заданное время
- **Обновление через git**: стартёр сам подтягивает новую версию и переустанавливается
- **Передача логов разработчику**: `doomsday logs-push` — в отдельную ветку `logs`

## Быстрый старт

```sh
git clone https://github.com/jadmag007/doomsday-bot.git ~/doomsday-src
bash ~/doomsday-src/install.sh
doomsday login
doomsday start
doomsday panel    # откроет веб-панель в браузере
```

## Команды

| Команда | Что делает |
|---|---|
| `doomsday start` | стартёр: git pull → при новой версии переустановка → сервисы + cron + контрольный проход |
| `doomsday stop` | остановить панель, cron-проходы, снять wake-lock |
| `doomsday panel` | открыть веб-панель в браузере (запустит её, если не работает) |
| `doomsday status` | таймеры и ресурсы прямо в терминале |
| `doomsday reboot` | ребут производства сейчас |
| `doomsday scan` | скан ресурсов сейчас |
| `doomsday check` | диагностика всех компонентов |
| `doomsday discover` | найти/проверить API игры (отчёт в reports/) |
| `doomsday summary` | сводка дня сейчас |
| `doomsday log -n 100` | хвост журнала |
| `doomsday logs-push` | выгрузить логи/отчёты в ветку `logs` репозитория |
| `doomsday git-auth` | сохранить GitHub PAT (git без запроса пароля) |
| `doomsday login` | вход в Telegram (интерактивно) |
| `doomsday setup` | мастер настройки |
| `doomsday web` | запустить веб-панель в этом окне (обычно не нужно — она живёт сервисом) |
| `doomsday selftest` | самопроверка без Telegram |

## Веб-панель

Адрес: `http://127.0.0.1:8080` (открывается командой `doomsday panel` — она сама
запустит панель и откроет браузер). Работает в любом браузере телефона, интернет
не нужен — панель живёт в Termux. PIN по умолчанию не задан; если смените
`web.host` на `0.0.0.0` (доступ из Wi-Fi) — обязательно задайте PIN.

Вкладки: **Дашборд** (цикл производства, скан, ресурсы под контролем, быстрые
действия, события), **Таймеры** (расписание и состояние), **Ресурсы** (карточка
«Под контролем», выбор ресурсов для уведомлений с иконками и поиском, остальные
склады), **Настройки**, **API / Discovery**, **Журнал**. Оформление — в стиле
игры: иконки ресурсов, фирменные цвета, шрифты.

Если после обновления вверху панели появился красный баннер «Код обновлён, но
панель работает старым процессом» — нажмите кнопку «Перезапустить панель»
(или выполните `doomsday start`): старый процесс был запущен до обновления и
раздаёт устаревший API.

## Как устроено обновление

Исходники — git-клон в `~/doomsday-src`, рабочая установка — `~/doomsday-bot`
(её трогать не нужно). Разделение нужно, чтобы live-правки `config.json` из
веб-панели никогда не конфликтовали с `git pull`.

- Разработчик пушит новую версию в `main` → на телефоне достаточно выполнить
  `doomsday start` (или `sh ~/doomsday-bot/start.sh`) — стартёр сделает
  `git pull`, увидит новую VERSION и молча переустановит код. Настройки,
  сессия и журнал не трогаются.
- После перезагрузки телефона всё поднимается автоматически (Termux:Boot).
- Логи и отчёты не синхронизируются с git: `logs/` и `reports/` — локальный буфер
  устройства. Передать их разработчику: `doomsday logs-push` (уходит в ветку `logs`,
  ветка `main` остаётся чистой, локальный буфер после отправки очищается).

## Структура проекта

```
doomsday-bot/
├── bin/doomsday        # CLI-точка входа (симлинк в $PREFIX/bin)
├── lib/
│   ├── paths.py        # пути установки
│   ├── config.py       # конфиг: дефолты, миграция, валидация
│   ├── db.py           # SQLite: события, ресурсы, запуски
│   ├── notify.py       # termux-notification
│   ├── tgapi.py        # Telethon: сессия, резолв Mini App URL
│   ├── tma.py          # драйвер API игры (Firebase preset + шаги)
│   ├── game_data.py    # статическая таблица ресурсов игры
│   ├── engine.py       # действия: scan / reboot / discover / check
│   ├── worker.py       # CLI + cron-планировщик
│   ├── starter.py      # doomsday start/stop/panel
│   ├── logspush.py     # doomsday logs-push / git-auth
│   └── webui.py        # веб-панель (stdlib http)
├── web/                # статика панели (SPA без зависимостей)
├── service/            # runit-сервис веб-панели
├── boot/               # автозапуск Termux:Boot
├── start.sh            # тонкая обёртка → doomsday start
├── install.sh          # установка/переустановка из ~/doomsday-src
├── uninstall.sh
├── INSTALL.md          # ПОДРОБНАЯ инструкция установки
├── VERSION
└── requirements.txt    # telethon
```

Рантайм (не в git): `config.json` — в git и синхронизируется (приватный репо!),
`session/`, `logs/`, `reports/`, `state.db`, `run/` — только на устройстве.

## Безопасность

- Репозиторий **обязан быть приватным**: в `config.json` лежат api_id/api_hash
  и телефон, в ветке `logs` — диагностика.
- Telegram-сессия (`session/`) никогда не попадает в git.
- PAT для git хранится только на устройстве (`~/.git-credentials`, права 600).
- Веб-панель по умолчанию слушает только `127.0.0.1` — снаружи не видна.

## История версий

- **2.2.0** — оформление в стиле игры: иконки всех 54 ресурсов, шрифты Europe/Iosevka,
  палитра игры (красный/золото), скошенные углы, логотип; вкладка «Ресурсы»
  переработана: карточка «Под контролем» сверху, поиск по каталогу, «остальные»
  свёрнуты; отслеживаемые ресурсы продублированы на дашборде; ЛЕЧЕНИЕ «висячего»
  процесса панели (после обновления старый процесс держал порт: пустой каталог
  ресурсов и дубли имён) — стартёр убивает все старые процессы панели по /proc и
  сверяет версию работающего кода, в панели — баннер с кнопкой
  «Перезапустить панель» и команда `doomsday web-restart`
- **2.1.0** — авто-ребут по игровому циклу: за N минут до конца (по умолчанию 10,
  `schedules.reboot_before_end_minutes`) вместо интервала «от последнего ребута»;
  убран второй таймер с дашборда; вкладка «Ресурсы»: выбор ресурсов для
  push-уведомлений (`notify.resource_filter`), все названия ресурсов на русском;
  сводка дня учитывает выбранные ресурсы
- **2.0.0** — удалён zip-обновлятор: установка и обновления только через git;
  новая команда `doomsday panel` (открыть панель в браузере); таймер цикла
  производства на дашборде; чистка legacy-файлов при установке; README/INSTALL
  переписаны; веб-панель проверяется в `doomsday check`
- **1.3.0** — встроенный рабочий API игры (Firebase callable): ребут и скан без
  настройки; команды `start`/`stop`/`logs-push`/`git-auth`; дедлайн цикла
- **1.2.x** — фикс Telethon-авторизации Mini App (BOT_APP_BOT_INVALID),
  discovery-error отчёты, доставка start.sh zip-обновлениями
- **1.1.0** — авто-поиск бота игры, git-стартёр, Termux:Boot
- **1.0.x** — первая рабочая версия: cron, уведомления, веб-панель, zip-обновления
