# Установка Doomsday Tyranny Bot — подробная инструкция

Всё ставится прямо на телефон, компьютер не нужен. Время: ~15 минут
(из них 10 — установка пакетов и вход в Telegram).

> Если что-то пошло не так — см. раздел «Устранение неполадок» в конце.
> Логи и диагностику всегда можно передать разработчику: `doomsday logs-push`.

---

## 0. Что понадобится

- Телефон Android 7+ с интернетом
- ~200 МБ свободной памяти
- Аккаунт Telegram (Premium — чтобы цикл производства был 12 часов)
- Доступ к приватному репозиторию `doomsday-bot` на GitHub (код + config.json)

## 1. Приложения: Termux + Termux:API (+ Termux:Boot)

Устанавливайте **из одного источника** (F-Droid или GitHub). Если Termux из
Play Market — удалите его, версии из Play Market несовместимы с надстройками.

| Приложение | Зачем | Обязательно |
|---|---|---|
| [Termux](https://f-droid.org/packages/com.termux/) | терминал, здесь живёт бот | да |
| [Termux:API](https://f-droid.org/packages/com.termux.api/) | push-уведомления | да |
| [Termux:Boot](https://f-droid.org/packages/com.termux.boot/) | автозапуск после перезагрузки | желательно |

Установив приложения, **откройте Termux:API и Termux:Boot по одному разу**
(пока приложение не открыто хотя бы раз, Android его «не видит»).

## 2. Подготовка Termux

Откройте Termux и выполните:

```sh
pkg update -y && pkg upgrade -y
pkg install -y git
```

## 3. Клонирование репозитория

```sh
git clone https://github.com/jadmag007/doomsday-bot.git ~/doomsday-src
```

Git спросит логин и пароль: логин — ваш GitHub username, пароль — **не пароль
аккаунта, а PAT-токен** (Fine-grained, права Contents: Read and Write на этот
репозиторий). Где взять: GitHub → Settings → Developer settings →
Fine-grained tokens → Generate new token.

Чтобы git не спрашивал токен при каждом pull — сразу сохраните его:

```sh
doomsday git-auth        # после установки (шаг 4); спросит токен скрытым вводом
```

## 4. Установка

```sh
bash ~/doomsday-src/install.sh
```

Установщик сам сделает всё: пакеты (python, cronie, termux-api,
termux-services), скопирует код в `~/doomsday-bot`, создаст Python-окружение
с Telethon, настроит cron (проход каждые 10 минут), сервис веб-панели,
автозапуск и глобальную команду `doomsday`.

На вопрос мастера настройки введите: `api_id` и `api_hash` (получить:
[my.telegram.org](https://my.telegram.org) → API development tools),
свой телефон, интервалы (по умолчанию: авто-ребут за 10 мин до конца цикла, скан 60 мин).

> **Два каталога — это нормально.** `~/doomsday-src` — git-клон (источник
> обновлений), `~/doomsday-bot` — рабочая установка (сессия, настройки, журнал).
> Так сделано, чтобы правки настроек из веб-панели никогда не мешали git pull.

## 5. Вход в Telegram

```sh
doomsday login
```

Введите код из Telegram-сообщения (и пароль 2FA, если он есть). Сессия
сохранится в `~/doomsday-bot/session/` — повторный вход не нужен.

## 6. Запуск

```sh
doomsday start
```

Стартёр поднимет всё: wake-lock (Android не усыпит Termux), веб-панель,
cron — и **сам откроет панель в браузере**: одна команда вместо
`start` + `panel`. В конце пришлёт push-уведомление с кнопкой
**«Открыть панель»** — оно заменяет само себя и всегда служит входом в панель.
Если после обновления версии стартёр пишет «перезапускаю стартёр на новом коде» —
это нормально: он перезапускает себя на свежеустановленную версию, чтобы
лечение «висячих» процессов панели сработало уже первым запуском.

Проверка, что всё живо:

```sh
doomsday check      # диагностика всех компонентов
doomsday status     # таймеры, балансы (данные/DDT), ресурсы в терминале
```

## 7. Веб-панель

```sh
doomsday panel
```

Команда запустит панель (если не работает) и откроет браузер на адресе
`http://127.0.0.1:8080`. Интернет для этого не нужен — панель живёт в Termux
на самом телефоне. Можно открыть адрес вручную в любом браузере.

- PIN по умолчанию не задан — панель открывается сразу
- Вкладка **Таймеры** — расписание (авто-ребут/скан/сводка), вкладка **Ресурсы** —
  карточка «Под контролем» с выбранными ресурсами, **автообмен** (балансы данных
  для серверов и DDT, правила: «при заполнении» с порогом или «сразу», запас
  «оставить»), каталог выбора с иконками и поиском (что отмечено — по тому и
  приходят push-уведомления), остальные склады (свёрнуты, чтобы не мешались),
  вкладка **Настройки** — уведомления, Telegram, веб-панель
- После обновления версии вверху может появиться красный баннер «Код обновлён,
  но панель работает старым процессом» — нажмите «Перезапустить панель»
  (или `doomsday start` в Termux); страница обновится сама
- Хотите открывать панель с компьютера в той же Wi-Fi сети: Настройки →
  Веб-панель → адрес `0.0.0.0` и задайте PIN (обязательно!) — панель станет
  доступна по `http://<IP-телефона>:8080`

## 8. Первый настоящий ребут (проверка автоматизации)

```sh
doomsday reboot
```

В ответе должно быть `rebootProduction ... ok` и «Новый цикл до <дата>» —
значит бот умеет перезапускать производство сам. После этого на дашборде
появится таймер «Цикл производства» с временем авто-ребута: бот сам
перезапустит цикл за 10 минут до конца — фарм не прерывается.

Какие ресурсы отслеживать (уведомления только по ним) — отметьте на
вкладке **Ресурсы** и нажмите «Сохранить выбор».

Проверить уведомления:

```sh
doomsday test-notify
```

## 9. Чтобы бот не умирал ночью

Android душит фоновые приложения. Два обязательных действия:

1. **Настройки → Приложения → Termux → Батарея → «Без ограничений»**
   (и так же для Termux:Boot).
2. Если производитель телефона агрессивен (Xiaomi, Huawei, Samsung и др.) —
   закрепите Termux в «недавних приложениях» (замочек) и/или отключите
   оптимизацию батареи для Termux. Подробно: сайт [DontKillMyApp](https://dontkillmyapp.com/).

## 10. Обновления

Обновления приходят через git — никаких архивов и загрузок:

- Разработчик пушит новую версию в репозиторий → вы на телефоне выполняете
  `doomsday start` (или просто `sh ~/doomsday-bot/start.sh`) → стартёр делает
  `git pull`, видит новую версию и молча переустанавливает. Настройки,
  сессия и журнал сохраняются. Обычно занимает 1–2 минуты.
- После перезагрузки телефона всё обновляется и запускается само
  (Termux:Boot → start.sh → doomsday start).
- Убедиться, что стоит последняя версия: `doomsday status` (первая строка).

## 11. Передача логов разработчику

```sh
doomsday logs-push
```

Соберёт хвосты логов, отчёты и конфиг, закоммитит в **отдельную ветку `logs`**
репозитория и запушит в GitHub. Ветка `main` не затрагивается, локальный буфер
после успешной отправки очищается. Разработчик заберёт логи из ветки `logs`
и разберёт.

## Устранение неполадок

**Панель не открывается / «не могу найти настройки»**
→ `doomsday panel` — команда сама всё запустит и откроет браузер. Не помогает:
`doomsday web` — панель запустится в текущем окне Termux, ошибки будут видны
сразу. Адрес для ручного ввода в браузере: `http://127.0.0.1:8080`
(именно http, не https; 127.0.0.1 — это сам телефон).

**Нет push-уведомлений**
→ Установлены и Termux-пакет `termux-api`, и приложение Termux:API из того же
источника? Приложение открывали хотя бы раз? Проверка: `doomsday test-notify`.

**Cron не работает ночью / ребуты пропускаются**
→ Пункт 9: батарея «Без ограничений», Termux не выгружен из памяти.
Проверка истории: `doomsday log -n 100`, события — в веб-панели (Журнал).

**git pull просит пароль**
→ `doomsday git-auth` и введите PAT. Ошибка «Authentication failed» — токен
истёк или без прав Contents: Read and Write на этот репозиторий.

**«sessionExpired» в логах скана/ребута**
→ Подпись Mini App устарела. Бот сам получает свежую при каждом проходе
(для этого нужен работающий вход). Проверьте: `doomsday check`. Если сессия
Telegram слетела — `doomsday login` заново.

**Порт 8080 занят**
→ Настройки → Веб-панель → смените порт (например 8090) → Сохранить →
«Перезапустить панель» → открывайте по новому адресу.

**Полный сброс**
```sh
bash ~/doomsday-src/uninstall.sh    # удалит установку и сессию
bash ~/doomsday-src/install.sh      # поставить заново
doomsday login && doomsday start
```
